# 连续多层嵌套揭示

[nested_world_reveal.py](nested_world_reveal.py)复用[旧单次函数](painted_world_reveal.py)的RGB/四角校验，新增完整层链和时序；[PW05](../standards/画中世界退出与载体揭示.md#continuous-nested-reveal)保存操作合同。Python、NumPy/OpenCV为必需依赖，CLI另需FFmpeg/libx264；核心像素体验不增加依赖。

```bash
python -m pip install -r requirements-painting.txt
```

仓库根可调用API，变量须由本作提供：

```python
from tools.nested_world_reveal import NestedWorldReveal
renderer = NestedWorldReveal(images, events)
frame = renderer.frame(t, layer_provider=None)
```

images按内→外排列，N≥2张同画布H×W×3 RGB，uint8或有限[0,1]浮点，禁止RGBA。N−1个event含非负有限start/end（end>start、顺序不重叠）及TL/TR/BR/BL凸四角，坐标基于准备后的共同画布；不接受原图或归一化坐标偷换。输出float32 RGB[0,1]，不改输入。

各层递归继承前层完整复合世界，累乘矩阵后每份原图采样一次，避免缩略复合图再放大。五次多项式缓动组织退出与驻留；provider(i,t)可提供该层同画布动态RGB，但动效由调用者实现。工具不调整尺寸、造图、生成角色动作/3D、音轨或字幕，不写剪映工程。

## cue与CLI

cue字段：canvas_size=[w,h]、fps、duration、assets=[图片路径]、reveals=[{start,end,quad}]。assets按cue目录解析；每张须预先明确裁切/留边到对应8位3通道画布。完整duration×fps为整数帧，最后退出不晚于duration。H.264 yuv420p宽高须为偶数。

```bash
python tools/nested_world_reveal.py --cue outputs/my-world/cue.json --check-only
python tools/nested_world_reveal.py --cue outputs/my-world/cue.json --output outputs/my-world/new-pilot.mp4 --start 0 --end 2 --ffmpeg ffmpeg
```

命令仅展示参数形式，实际cue/输入必须先准备；--start/--end是完整cue时间，须落帧格。输出目录须已存在，MP4及同名.render.json任一已存在均拒绝覆盖；失败部分文件不能当有效交付。--check-only只核输入，不渲染/不证明视觉通过。

输出静音MP4及本机.render.json，记cue/源图/实现/验证器SHA、实际请求帧数和取样范围；其中本机路径只供运行定位，不提交公开库。编码成功后仍需实际全解码/规格检查，正常速度观看、听审和采用分别记录。未知能力不冒充执行，不把外部合成称原生剪映制作。
