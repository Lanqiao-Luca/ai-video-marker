# 抽取与复现记录

来源作品：PIXEL-010《屋顶晒太阳》，原版44秒/24fps/720×1280。此次以真实作品作为效果基线，具体公开候选仍待用户审片。

| 阶段 | 本次处理 |
|---|---|
| 来源冻结 | 绑定原绘图脚本、场景JSON及来源SHA |
| 代码抽取 | 18个原绘图函数原样提取；去掉强绑定音乐的旧CLI，另加校验和执行适配 |
| 配置 | 保留原对象、角色路径、机位、时长与fps；视觉配置移除旧机器音频路径；音频另随包保存并核SHA |
| 代表段 | 先导出16–20秒拉叶解卡段，核原角色/背景/接触与编码样本 |
| 全片 | 保留44秒静音母版，再以原0–44秒WAV生成带音乐版；1056帧画面回归不变 |
| 音乐 | 新编44秒程序合成配乐随源码采用MIT许可；完整艺术听审未运行 |
| 采用 | 尚待用户审阅，不自动把复现成功当创作采用 |

代码来源和公开适配身份见 [provenance](../../docs/provenance.json)，效果保持和最终编码见 [验证记录](../../docs/VALIDATION.md)。
