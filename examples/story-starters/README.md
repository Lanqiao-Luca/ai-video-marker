## 第一次怎么选

| 这次目标 | 先走哪一步 |
|---|---|
| 立刻体验包内视频 | 返回[新手体验](../../README.md#做你的第一支视频)，默认用海港机器人素材做短预览与全片 |
| 想换故事，先看文字 | 选择下方任一开场，把需求复制给AI；13–18默认先交文字计划 |
| 已有自己的图/音/工程 | 直接告知路径、采用身份与想改的动作，按对应流程核输入，复用有效结果 |
| 缺关键姿势或画面 | 先看[素材中心](../../assets/README.md)及模块说明；完整姿态/拆件/图集分开核，缺项再选择补图或换方案 |

新生图/配音可能更慢并增加Token或服务调用费用；先列真实缺项，再按已给授权处理。视频成片是展示资源，不等于原始分层图或可编辑工程。
