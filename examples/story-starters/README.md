# 12个视频案例开场

每个案例包含一句可作片头字幕或旁白的开场文案，以及一段可以复制给AI的制作需求。先打开本仓库，再复制喜欢的一段；阅读文案无需下载媒体文件。

这些是创作提案，选定后由AI按工作流适配分镜、动作与实现。已有三个可运行场景仍见[项目入口](../../README.md)，新文案不代表已经附带对应成片。默认新人机器人短片保持不变。

## 01 没有收件人的信

**开场文案**：这封没有收件人的信，最后到了它自己手里。

```text
按本仓库的通用故事流程，做一支30秒温暖绘本短片《没有收件人的信》。狐狸邮差沿村庄寻找一封空白信的主人，獾、小鸟和门前的灯先后给出线索，最后发现信里画的是它一路帮助过的朋友。
优先复用woodland-friends中的角色和背景，选定一种狐狸造型保持全片一致，音乐先用包内原创配乐；缺少的角色或场景先列出来，不自行生图或付费调用。先给6镜头分镜和5秒代表段，我确认后再扩全片，输出写到新的outputs/lost-letter目录。
```

## 02 把晚霞留到明天

**开场文案**：它想把今天最好看的那一分钟，留给还没回来的朋友。

```text
用本仓库的sunset-room素材，做一支30秒绘本短片《把晚霞留到明天》。机器人搬来凳子等朋友，窗外的晚霞一点点退去；它用纸画下窗景，朋友回来后，两人把画贴在窗边，给明天留了一个位置。
采用包内圆润机器人，保留房间与凳子的空间关系。新朋友若缺素材，先提出复用或用影子表达的方案，不直接更换角色。先出分镜和5秒推凳代表段；音乐复用包内原创曲，确认后再做全片，写入新的outputs/save-the-sunset目录。
```

## 03 红绿灯休假一天

**开场文案**：红绿灯熄灭以后，一只小鸟接过了指挥棒。

```text
按像素工作流，做一支32秒无对白短片《红绿灯休假一天》。旧信号灯失灵，小鸟先用翅膀提醒第一辆车，行人接着排出通行队形，修好的灯最后跟随大家的节奏恢复工作。每一步都保留新的通行秩序，结尾回到同一个路口全景。
优先用本地程序绘制路口、车辆和信号灯，保持统一像素风格，不额外调用生图或付费服务。先给对象布局、动作因果与5秒指挥代表段；音乐可复用包内原创曲。确认后扩全片，写入新的outputs/traffic-light-day-off目录，不套用已有灯塔剧情。
```

## 04 云朵面包店

**开场文案**：今天的第一位客人，是一朵忘了下雨的云。

```text
做一支36秒像素短片《云朵面包店》。云朵把最后几滴雨留在门口，面包师用雨水和面，烤箱蒸汽托起一只面包气球；气球把云送回天空，轻雨让门前花盆发芽。用和面、发酵、膨胀建立可见进展，最后兑现气球的新用途。
场景和道具优先用程序绘图，音乐先复用包内原创曲。不要默认换成兔子或机器人；主角形象先给文字方案与程序样图。先交分镜和5秒膨胀代表段，确认后扩全片，写入新的outputs/cloud-bakery目录，不额外调用生图或付费服务。
```

## 05 一枚纽扣的搬家

**开场文案**：从衣角掉下来的那天，它第一次看见了整个房间。

```text
沿定格动画流程，做一支20秒纸艺定格短片《一枚纽扣的搬家》。纽扣从衣角滚下，先借铅笔跨过桌缝，再沿线头滑到纸盒，最后成为纸盒小屋的圆窗。让每件道具通过自己的形状帮助它前进。
先用程序纸纹和几何形状实现，不新增外部素材。以逐格姿态与曝光保持呈现定格感，具体帧率先说明；不把平滑镜头移动当成主体定格动作。先给分镜和4秒跨缝试段，确认后扩全片，写入新的outputs/button-new-home目录。无需旁白，音乐复用包内原创曲。
```

## 06 纸飞机的返航

**开场文案**：它飞了很多次，每次都回到那张小小的桌子。

```text
按定格动画流程，做一支24秒短片《纸飞机的返航》。纸飞机三次起飞：第一次被书挡住，第二次借尺子滑翔，第三次带回一枚窗边的花瓣。最后它停在一张未写完的卡片上，机翼展开成为卡片的一部分。
优先用程序绘制纸飞机、桌面与道具，不调用新生图或付费服务。固定同一桌面地图，给每次尝试不同的动作结果。先做动作表和4秒起飞代表段，确认后扩全片，写入新的outputs/paper-plane-return目录；音乐使用包内原创曲。
```

## 07 雪落在江面之前

**开场文案**：雪下了很久，江面只剩一叶船。

```text
沿古诗词动画流程，用柳宗元《江雪》做一支约40秒学习短片《雪落在江面之前》。优先复用snow-river中的无字江面和独立渔舟；先建立山、路、船的空间，再逐句呈现诗意，结尾保留完整诗文复习。开场文案与原诗明确区分，不把改写当成诗句。
先核对原文、字音与字幕，再给逐句分镜；有可用配音能力时先出8秒声样，没有时先做字幕静音方案，不自动调用付费配音。先做5秒船与水面接触代表段，确认后扩全片，写入新的outputs/snow-river-poem目录。
```

## 08 竹子的回答

```text

先核诗文和字音，再给声画分镜；配音先核实际工具并出短声样，没有可用能力就给字幕/静音方案，不付费调用。先做5秒风中近景，说明静图有限动画能做到的范围，确认后扩全片，写入新的outputs/bamboo-answer目录。
```

## 09 把没说完的话还给风

**开场文案**：有些话没有说出口，也能慢慢放下。

```text
按仓库情绪诗词候选流程，做一支25秒短片《把没说完的话还给风》。用原创短句写一次安静的告别：折好的纸、合上的书、窗边的风，最后纸被展开，成为一张新的空白。先写三段短文与字幕节奏，避免把原创句子署给古人或引用流行歌词。
优先复用poetry-book和兼容的现有背景，保持同一画风，音乐先用包内原创曲。先给文字稿、三幕分镜和5秒声画样段，确认后扩全片，写入新的outputs/words-to-the-wind目录。不自动生图、配音或调用付费服务。
```

## 10 今晚允许自己慢一点

**开场文案**：今天走得慢一点，也没关系。

```text
沿情绪诗词候选流程，做一支24秒原创短句短片《今晚允许自己慢一点》。从窗边的晚霞、桌上的杯子和慢慢合上的书，写出一天结束时的松弛感。全片只用三段简短文字，避免堆砌口号，让每次停留都有一个可观察的小动作。
优先复用sunset-room和poetry-book中风格兼容的画面；不兼容时先给取舍方案，不直接混贴。音乐复用包内原创曲，默认字幕表达。先交文案与5秒代表段，确认后扩全片，写入新的outputs/slow-evening目录，不新增生图或付费服务。
```

## 改成自己的题目

保留喜欢的机制，再替换角色、地点或最终回报。例如“纽扣成为圆窗”可以改成“瓶盖成为唱片”；换主题时同步改动作因果与物体用途，不只改标题。制作请求中的outputs目录名也应更换，保护已有结果。

需要重新生成图片、声音或其他素材时，先说明缺项和实际成本，再按用户已给授权推进。案例文案只作为当前作品起点，不增加仓库的已实现媒体能力或候选流程效力。
