# 雪江与独钓渔舟

取自《江雪》的2张既有原画：snow-river.png为完整无字背景，fishing-boat.png为独立渔舟。尺寸、通道、源/公开SHA见[manifest.json](manifest.json)。未纳入旧分镜标注、朗读或配乐。

```bash
python tools/asset_library.py verify --pack snow-river
python tools/asset_library.py preview --pack snow-river --out outputs/snow-river-preview.png
```

可设计冬日独钓或雪江来信，适配船位移、水面接触与镜头推拉。静图有限变化不代表完整角色动作；preview是资产联系表，新剧情仍需动画实现。PNG原字节复制、原件不变，按[MIT](../../../LICENSE)公开。
