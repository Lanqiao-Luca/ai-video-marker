# 图片素材

现有图片保留原路径：

- [制作素材精选](../library/README.md)：10组73张PNG，含角色、拆件、图集和背景。
- [机器人与海港素材](../harbor/README.md)：12张PNG及可编辑绘图源码。

本目录当前仅有分类说明。后续新增可复用图片按素材包放入 `images/素材包ID/`，附实际用途、尺寸/透明通道、来源、许可与必要清单。完整姿态、角色拆件和图集按真实内容区分；一张图集不按格数算多张PNG。

案例专用展示封面可随案例保留在 `examples/`；制作中间帧和缓存不当作可复用素材重复上传。不要为统一目录搬迁已有图片、破坏工具路径或已有SHA清单。
