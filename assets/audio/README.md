# 音频素材

当前模块[pixel-rooftop原创配乐](pixel-rooftop/NOTICE.md)：[music.wav](pixel-rooftop/music.wav)、[source.json](pixel-rooftop/source.json)，[合成源码](../../tools/make_demo_music.py)仍在tools。

默认三个像素场景读取同一份配乐，音频按模块实际存放，不在每个案例重复打包。漫画配乐已混入展示成片，本仓库没有提供其独立音轨或工程。

后续配乐和音效放audio/模块ID/，附来源/生成方式、再分发许可、时长、规格、用途与版本。实际录音身份、偏移、裁切/淡化独立记录，不能用同名歌曲代替同一录音；本地拥有不等于允许再分发。工具不会因短音频自动循环或改速，详见[音轨工具](../../tools/README.md)。
