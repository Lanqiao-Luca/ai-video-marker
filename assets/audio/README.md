# 音频素材

现有可复用配乐保留在像素案例目录：

- [原创配乐WAV](../../examples/pixel/audio/music.wav)
- [来源与许可记录](../../examples/pixel/audio/source.json)
- [程序合成源码](../../tools/make_demo_music.py)

音轨仍使用原路径，已有像素示例无需改配置。漫画案例的音乐已混入其成片，本仓库没有因此提供它的独立音轨或制作工程。

本目录当前仅有分类说明。后续获准公开的配乐、音效按 `audio/用途或素材包ID/` 存放，附真实来源/生成方式、再分发许可、文件规格、时长、用途与版本，必要时记录SHA。歌曲版本、音源偏移及裁切/淡化按实际记录，不能用同名歌代替相同录音。

下载、聆听或本地已有音频不等于可以再分发；不能把未知许可录音随源码许可证一并授权。音频文件不够长时，不默认循环或改速；使用工具及限制见[音轨工具说明](../../tools/README.md)。
