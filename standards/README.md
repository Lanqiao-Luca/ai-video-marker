# 制作标准


五 AP 管目的、复用、证据、原件和采用基线；AN01–AN10 管策划、画面、动作、声音、验证与恢复。
像素十二条方法、纸艺 PB01/PB02、情绪诗词 PSV01–04 为专题方法。纸艺与情绪诗词保持候选身份。
EX01 与 RET01 保存最小执行记录和产物归属；公开版不依赖私有治理工具。

## 结果交回

新作品开工前使用 [素材准备与生成预算](素材准备与生成预算.md)明确复用、补缺或从零制作，并说明真实成本。

把所用方法、实际结果、版本、证据范围和首断点交回调用技能；不因方法文档存在而声称视频已经制作或验收。
