## 结果交回

新作品开工前使用 [素材准备与生成预算](素材准备与生成预算.md)明确复用、补缺或从零制作，并说明真实成本。

把所用方法、实际结果、版本、证据范围和首断点交回调用技能；不因方法文档存在而声称视频已经制作或验收。
