# BL04 角色表演与曲线精修

**输入**：本片人物任务/情绪、注视对象、动作/声音cue、已核绑定及关节测试、采用美术与本轮反馈。AN04仍负责风险段选择/动作制作，AN10仍负责因果与场内主次，AN07/08负责验收/同候选交接；本页只补角色表演和Blender曲线的专业处理顺序。

**动作**：
1. 把本镜要表达的意图写成可观察的关键姿态与反应：看向哪里、何时抬头/抬手、接触或完成后如何收势。先做关键姿态blocking，检查剪影、重心/胸肩关系、手与道具、视线和面部是否表达同一任务。镜头无表情特写时不强制制作全部脸部控件；静态脸无法承担任务则回美术补所需表情/分层，不用头部扭曲代替。
2. 在关键姿态可读且BL01关节测试就绪后补过渡，按本片意图调整弧线、预备、加减速、幅度、停顿及收势。肩臂串动、肢体长度/轮廓失真先回rig；关键姿态不对回编排/美术，不先用曲线平滑掩盖。姿态变化需要可控关节关系，不以大范围二维区域整体位移替代抬臂。
3. 视线、眼睑、眉形、嘴及头颈按所需信息分别用校准的分层表情、shape keys或既有控制器；单独核身份、瞳孔目标与表情极值，再核身体/神态协调。眼、头、手可以有本片设计的先后，也可同时或有意迟滞，不固定所有作品的毫秒次序。按角色意图保必要稳定/注视，不能以一直摆头证明神态。
4. 绑定/姿态就绪后，选相交通道与时间段调F-curves的缓入缓出、过渡、偏移和幅度；保原动作及cue对照，避免影响无关通道/段落。AnimAide等是可选精修工具，未安装时可用现有Graph Editor/脚本等效操作，不为读本方法自动安装。衣发/附件跟随服务主动作，先检主表演再加次动作，不默认所有部位连续正弦摆动；有意循环依场景核其用途。
5. 沿AN04已选风险集合做本片最小必要连续试段，必要时暂固定机位或屏蔽运镜以看清肩臂/脸部；这不是要求成片取消运镜。观察开始/中段/极值/完成，正常速度连续看动作幅度、受力/弧线、神态意图与主次协调，按本片风格判断；静帧、骨骼位移、解码无错均不代自然表演。未正常速度审看保持UNKNOWN，核心表演必要失败回相交plan/art/rig/motion，不因技术通过扩片。

**输出/返回**：在既有镜头/动作记录补本片意图、注视目标、关键姿态及过渡、控制通道/时间范围、连续试段与批注、失败/未验；不建第二时间线。关节测试通过只证明本片所测机制，主观自检、专职审查及Owner采用分别交原职责记；修改的曲线/绑定/表情交BL03求缓存失效范围。
