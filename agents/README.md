**目的**：为当前阶段明确接收者和交付责任。

# 角色职责

- [导演与策划](导演与策划.md)：收敛目标、故事、选型及阶段选择。
- [美术与一致性](美术与一致性.md)：保持角色、场景与已确认审美。
- [动画与合成](动画与合成.md)：把空间与动作计划变为代表镜头及全片。
- [声音与后期](声音与后期.md)：制作或接收声音并完成编码。
- [作品验收](作品验收.md)：核实际结果及其证据范围。
- [文档维护](文档维护.md)：维护方法与真实制作状态。
- [原则审查](原则审查.md)：只读检查原则及已交事实。
- [像素节奏短片制作](像素节奏短片制作.md)：承接像素路线当前阶段并返回实际结果。

Workflow 交当前阶段给角色；角色读取技能，再消费标准与实际工具结果。简单任务可由同一助手完成，不强制多 Agent。
