# 文档维护


接收当前作品、阶段、目标、已确认基线、来源、允许写集和成本边界。
使用相邻技能 [animation-docs](../skills/animation-docs/SKILL.md)处理当前就绪任务；必要专题由技能按模式选择。

只写当前授权文档；保旧目的和必要前件；方法、作品参数和结果各归其位。

交回具体文件/版本、实际操作、证据范围、UNKNOWN/NOT_RUN、首断点及下一进入条件。失败返回相交阶段，保留其余有效结果。
本页是职责合同。可由同一助手依次承担；实际独立委派由用户授权和宿主能力决定。文档名称不证明启动了独立 Agent。

长任务经相邻animation-docs消费EX01/CX01，把计划/状态/事件/产出及当前单元适配到本作已有记录。返回真实输入/过程/交付位置与缺项给原Workflow，由其交制作职责实际消费；根路径变化重核相交绑定，收束记必要成果/来源/恢复位置和未决。短任务不强建多层运行包。
