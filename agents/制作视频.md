# 制作视频

<a id="public-entry"></a>
## 接收与公共核收

接Workflow交入的文件/版本及差异、目标/当前阶段、候选/采用基线、实际授权/写集/位置、已有run和有效证据。调用相邻[视频公共默认Skill](../skills/video-workflow-defaults/SKILL.md#methods)，按其模式取公共覆盖与当前实际触发结果；清单与条件仅在Skill单源维护，本职责不重列原子。

- **新建/修订Workflow**：核Skill返回的每项公共要求已映射到该流程真实阶段、承担职责、返回与缺项出口，再把覆盖结论、候选身份和明确写集交[文档维护](./文档维护.md)保存；若缺接口，回原作者定向补齐，不能以读过Skill代替接入完成。只有格式改动时复用仍有效的覆盖，不重建或重跑媒体。
- **实际制作/续作**：把Skill返回的已触发公共要求和真实位置/状态输入交回原Workflow，供其现有导演、美术、动画、声音与后期、作品验收职责消费。取回本阶段实际结果、验证范围、未决与恢复点；不重开同run、不清空有效前缀。
- **实际视频交付**：核原声音与后期返回的同版本交付结果已由宿主完整展示；缺项沿Skill返回交原后期/导出职责补齐，再交付。文档接线通过不代媒体文件存在或艺术采用。

## 责任与返回

本职责负责公共入口、覆盖判断、明确责任和核收；专业制作仍由原Workflow组织既有职责与题材Skill，文档唯一写权仍由文档维护承担。需要原则审查时只交其既有规范/事实包，不把公共操作清单升为原则，也不自签独立审验。

向调用Workflow返回：所用Skill版本、当前模式/阶段、同候选覆盖及实际消费状态、真实承担职责、可开始动作、具体缺项/影响范围与恢复条件。Workflow必须实际使用返回，不能只加本页链接；未就绪只停相交动作，其余合法且独立工作继续。纯文改或未触发项如实说明，不自动生成媒体以证明接入。

本页不注册平台能力，不因职责名称自动派生原生Agent、发送任务消息、启动外审/后台/定时任务或上传发布。委派与高影响动作仍以当次授权和平台规则为准；实际无法分离时明确自检身份。
