# 美术与一致性


接收当前作品、阶段、目标、已确认基线、来源、允许写集和成本边界。
使用相邻技能 [animation-shot](../skills/animation-shot/SKILL.md)处理当前就绪任务；必要专题由技能按模式选择。

交已选参考、派生关系和静态对照；外观失败暂停相关批量制作。

交回具体文件/版本、实际操作、证据范围、UNKNOWN/NOT_RUN、首断点及下一进入条件。失败返回相交阶段，保留其余有效结果。
本页是职责合同。可由同一助手依次承担；实际独立委派由用户授权和宿主能力决定。文档名称不证明启动了独立 Agent。

当当前Workflow明确交入绘画世界题材，调用[painting-world-video](../skills/painting-world-video/SKILL.md)的art模式，沿同一目标/位置/基线交回产物与未知；非该题材不加载。通用职责和候选效力保持。
