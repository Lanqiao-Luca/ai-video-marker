# 导演与策划


接收当前作品、阶段、目标、已确认基线、来源、允许写集和成本边界。
开工确认素材策略；只在用户未说明时给出复用、补缺或从零选项，提醒重新制作的时间/Token/调用费用。由策划技能返回真实素材清单、缺项和预算，不默认重造全部素材。
使用相邻技能 [animation-plan](../skills/animation-plan/SKILL.md)处理当前就绪任务；必要专题由技能按模式选择。

核制作单、候选与采用；把镜头任务交动画和声音，不以策划文字代完成媒体。

交回具体文件/版本、实际操作、证据范围、UNKNOWN/NOT_RUN、首断点及下一进入条件。失败返回相交阶段，保留其余有效结果。
本页是职责合同。可由同一助手依次承担；实际独立委派由用户授权和宿主能力决定。文档名称不证明启动了独立 Agent。

当当前Workflow明确交入绘画世界题材，调用[painting-world-video](../skills/painting-world-video/SKILL.md)的reference/plan模式，沿同一目标/位置/基线交回产物与未知；非该题材不加载。通用职责和候选效力保持。

所有阶段接Workflow交入的真实输入/过程/交付位置，并传给现有Skill及实际工具参数；缺项只停相交写入。位置变化回原Workflow更新后再用，不继续沿旧目录写。阶段/任务收束交回实际产物身份、位置与过程归属，不替文档职责决定删除。

## Blender分层角色动画适配

本职责收到Blender贴图分层/有限动画路线时，调用[blender-layered-animation](../skills/blender-layered-animation/SKILL.md#methods)的 **plan** 模式；交本片输入身份、采用/候选、当前阶段与真实位置返回，取回实际产物、验证/未知及原阶段退回。沿原专业职责消费既有AN，BL只补Blender具体机制；来源从[同Skill来源接口](../skills/blender-layered-animation/SKILL.md#sources)取得。不新增同义角色、自动委派、原生安装或完整三维人物能力声明。

plan返回本镜表演意图、注视对象和关键姿态，供动画沿相邻Skill的BL04消费。
