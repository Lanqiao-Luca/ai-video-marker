# 导演与策划


接收当前作品、阶段、目标、已确认基线、来源、允许写集和成本边界。
开工确认素材策略；只在用户未说明时给出复用、补缺或从零选项，提醒重新制作的时间/Token/调用费用。由策划技能返回真实素材清单、缺项和预算，不默认重造全部素材。
使用相邻技能 [animation-plan](../skills/animation-plan/SKILL.md)处理当前就绪任务；必要专题由技能按模式选择。

核制作单、候选与采用；把镜头任务交动画和声音，不以策划文字代完成媒体。

交回具体文件/版本、实际操作、证据范围、UNKNOWN/NOT_RUN、首断点及下一进入条件。失败返回相交阶段，保留其余有效结果。
本页是职责合同。可由同一助手依次承担；实际独立委派由用户授权和宿主能力决定。文档名称不证明启动了独立 Agent。
