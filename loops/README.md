# Loop：局部迭代

[镜头迭代](镜头迭代.md)用于代表镜头/接缝的定向修订。单轮执行经[Workflow](../workflows/README.md)交阶段角色，角色取Skill再消费标准；Loop不直调底层方法，也不启动后台。

进入时接目标、问题时点、采用/候选身份、允许改点、输入/输出位置、剩余轮次与成本；退出时返回真实轮数、检查范围、未决和原阶段。简单文改或一次制作直接用Workflow。

实际启用时把循环状态写入本作已有[项目记录](../templates/project/README.md)，不另建第二份总体状态。Graph可经本层接口取得执行流程；没有重复需求时直接向现有阶段Workflow交接，不强建循环实例。
