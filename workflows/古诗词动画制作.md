# 古诗词动画


面向学习与理解；情绪表达优先的作品使用候选情绪诗词流程。

| 阶段 | 负责与产物 | 条件/返工 |
|---|---|---|
| 1 核文本与范围 | 导演：作者、原文/版本、字音、来源及学习点 | 原文、释义和创作解释分开 |
| 2 早期声音 | 声音：真实可试听短样及工具/音色/来源 | 字音、自然度、唱法问题先修声音；朗诵不称演唱 |
| 3 稳定音轨与 cue | 导演/声音：逐句时点、字幕和镜头对应 | 全片 cue 依全片稳定音轨；声样只覆盖局部 |
| 4 美术与空间 | 美术/动画：角色、机位、接触与诗意说明 | 比喻与真实物分开，变方向交用户 |
| 5 连声字幕试镜 | 动画/声音：风险段实际编码 | 抬低头等需真实姿态变化，不能用拉远冒充 |
| 6 全片与混音 | 动画/声音：正文、必要声轨与 cue | 核人声清晰、配乐、接点和尾音 |
| 7 学习包装 | 导演：可选独立片头、正文、全文复习与总时间线 | 长诗按字量分页，独立采用不外推新组合 |
| 8 实际导出/验收 | 验收：同候选技术、字音/字幕、完整听看 | 指定剪辑软件须有真实工程/导出 |

不默认观众一定是儿童；声线、时长、布局、fps及响度按本作选择。已有采用声线可复用，只试新风险。


执行时先恢复当前项目和有效基线；缺项只停相交步骤。各阶段交入目标、输入、写集与成本边界，交回具体产物、实际检查、未知和下一进入条件。
职责见 [agents](../agents/README.md)，技能由角色按当前阶段选择；必要返工直接回相交阶段，首次本地分享不另装循环或图执行器。

<a id="video-delivery-handoff"></a>
## 视频版本交付出口

本流程向用户交付已实际导出的视频版本（成片、初稿或试片）时，将本次文件/版本、实际内容与已知发表渠道交[声音与后期交付职责](../agents/声音与后期.md#video-delivery)，接回相邻Skill生成的完整交付信息，由宿主在最终回复实际展示。具体必交项由该职责消费的唯一原子定义，本页不复制正文。缺文件回原导出阶段，缺文案由原职责补齐；纯文档/归档结果、内部编码测试与未交付中间片不触发，不因此新做视频或自动发布。既有阶段、候选效力与采用条件保持。

<a id="video-public-entry"></a>
## 视频制作公共接入与返回

新建/修订本流程或实际进入、续作、视频/宣传交付时，将本候选版本/差异、目标阶段、基线、写集/位置、已有run和有效证据交[制作视频职责](../agents/制作视频.md#public-entry)，接其相邻公共Skill返回。入口不改变本流程方法状态或专用制作责任。

| 模式/落点 | 当前承担职责与实际消费 | 返回与缺项出口 |
|---|---|---|
| 流程候选接入 | 制作视频核逐项触发、阶段、职责与返回；文档维护核同候选覆盖后保存 | 接线覆盖与本轮媒体执行分列，缺接口回原作者，不以链接存在替代消费 |
| 当前制作/续作：文本/逐句声画与全文复习编排 | 导演/动画按原题材Skill接已触发公共项；节奏判断/反馈进入animation-shot的AN13适配，声音取权威cue；文档维护接属性、位置和同run记录 | 返回需改/复用、真实时序/新增信息、验证与未知；缺项只停相交动作，保有效前缀 |
| 美术阶段：逐句画面与风格 | 美术保持本片采用身份；宣传或单独封面触发时取animation-shot静态封面适配 | 真实图像/来源/检查交回后期；无工具交可恢复输入，不假称出图 |
| 后期/交付：早期声样、逐句同步与最终验收 | 声音与后期消费原视频交付出口；宣传封面结果取animation-finish封面适配，由制作视频核收后交宿主展示 | 缺视频回导出、缺封面只回相交图；非宣传不强制补图，补字段不重渲或发布 |

保存覆盖与实际结果沿本作已有计划/状态/事件/产出，格式见[公共覆盖空模板](../templates/project/public-defaults.md)。每项写原子ID/有效版本、触发、职责、阶段、证据/缺项和下一消费者；未触发注明条件/有据N/A，不能把空表当已消费。纯接线改动不生成媒体，专业工具能力与正常速度听看须以实际执行为准。
