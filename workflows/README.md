**目的**：按用途选择一条主流程，从当前真实阶段进入。

# 制作流程

首次体验且没有自定义要求时，先沿像素流程复用仓库自带示例素材，生成短预览及完整视频；不先询问用户本地图片/音乐。用户开始自己的新作品时，才由导演交策划技能确认素材来源、复用/补缺/从零与成本说明。需求已明确时沿用；方法由策划技能消费素材准备标准。

- [通用故事短片](短片制作.md)：故事、角色行动、镜头因果与后期；正式流程。
- [古诗词动画](古诗词动画制作.md)：文本与字音、早期声音、逐句声画与全文复习；正式流程。
- [定格动画](定格动画制作.md)：路线、曝光保持、接触锚点与逐格节奏；正式流程。
- [像素节奏创意短片](像素节奏创意短片制作.md)：物体结构触发、累积回报、音乐和连续空间；正式流程。
- [情绪诗词短视频](情绪诗词短视频制作.md)：参考拆解、情绪脚本、声音和字幕母版；候选流程。
- [歌词／短句驱动程序动画MV](歌词驱动程序动画MV制作.md)：真实声音/文字、材质与事件、观看兑现和风险覆盖；纸艺为分支，保持候选。
- [绘画世界穿行短片](绘画世界穿行短片制作.md)：先定结尾逆推路线，核关键帧、接缝及可选画框退出；候选方法，未附整片渲染器。

辅助流程：[作品归档与复用](作品归档与复用.md)、[文档维护与原则审查](文档维护与原则审查.md)。
共7条内容流程（4正式、3候选）及2条辅助流程。文档状态与渲染实现可用状态分别见 [catalog.json](../catalog.json)。

长任务经[文档维护职责](../agents/文档维护.md)与其Skill组织同一项目的计划、状态、事件和产出记录，传实际输入/过程/交付位置给制作职责；位置变化先更新绑定，收束返回产物和过程归属。实际循环与依赖分别沿[Loop](../loops/README.md)、[Graph](../graphs/README.md)按需组织，简单任务不必全部启用。
