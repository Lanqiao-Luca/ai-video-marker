# 歌词／短句驱动程序动画 MV


候选路线从纸艺分支扩展为按真实声音、文字与材质选择方法。原`paperbook`路线ID保留兼容；新增的材质选择不等于已实现通用换歌产片引擎，也不改变候选状态。

| 阶段 | 责任与产物 | 进入条件/失败去向 |
|---|---|---|
| 范围与参考 | 导演：观看用途、目标画布、声音/文字类型、既作差异、观看承诺与材质 | 只换标题/配色不足以称新创意；未知只停依赖 |
| 真实声音与事件 | 声音/导演：实际录音/原创输入、来源用途、片段/SHA、事件基准/版本/偏移/可信度 | 精确事件未冻结不合片；无歌声的短句配器乐不称已演唱MV |
| cue与主动作 | 导演/动画：经animation-plan/shot返回逐场动作链、阶段结果/接续、cue与节奏/停顿用途，同交已知/新增信息与兑现 | 停留可有表达目的；结尾没有新增信息不误称反转 |
| 材质与舞台 | 美术/动画：目标画布预演、层序/支点/接触；纸艺才加纸页/图集/折页 | 现有通用阶段Skill处理非纸艺，匹配纸艺才取paperbook-mv |
| 风险连续样段 | 动画/声音/验收：核心机制、接触、变形/换场与关键事件覆盖，核动作链阶段结果/接续，交实际看听范围或UNKNOWN | 其他难点通过不代卖点已验；必要失败回相交试段 |
| 全片与修订 | 动画/声音：有效前缀、工程/输入、全片候选及必要静音母版 | 共享时序/资产变化只重核真实失效部分 |
| 编码与实际检查 | 声音/验收：容器/码流、全解码、AN10场内表现/反证、静帧、正常速度看听与感知同步各自结果 | 退出0/联系表/相关值不代完整听看；未验如实交候选 |
| 反馈与复用 | 导演/文档：关联用户原反馈/版本、具体修订、真实新反馈与未确认；保采用/未验和恢复位置 | 技术PASS不关闭动作不足反馈；仅待真实体验反馈不自动重修/重渲；交付不等于已发布 |

五角色先使用[animation-plan](../skills/animation-plan/SKILL.md)、[animation-shot](../skills/animation-shot/SKILL.md)、[animation-finish](../skills/animation-finish/SKILL.md)；纸艺分支才按[paperbook-mv](../skills/paperbook-mv/SKILL.md)的plan/art/motion/sound/review取PB/AN。文字可选，每首歌曲或原创短句都有本片动作与时间结构。


执行时先恢复当前项目和有效基线；缺项只停相交步骤。各阶段交入目标、输入、写集与成本边界，交回具体产物、实际检查、未知和下一进入条件。
职责见 [agents](../agents/README.md)，技能由角色按当前阶段选择；必要返工直接回相交阶段，首次本地分享不另装循环或图执行器。

制作前经文档维护职责及animation-docs保存本作位置/计划；位置变化先回原流程更新，收束交实际产物与过程归属。长任务沿同一状态接续，不搬入私有案例或默认套用旧片时长/镜头数。

## 视频版本交付出口

本流程向用户交付已实际导出的视频版本（成片、初稿或试片）时，将本次文件/版本、实际内容与已知发表渠道交[声音与后期交付职责](../agents/声音与后期.md#video-delivery)，接回相邻Skill生成的完整交付信息，由宿主在最终回复实际展示。具体必交项由该职责消费的唯一原子定义，本页不复制正文。缺文件回原导出阶段，缺文案由原职责补齐；纯文档/归档结果、内部编码测试与未交付中间片不触发，不因此新做视频或自动发布。既有阶段、候选效力与采用条件保持。
