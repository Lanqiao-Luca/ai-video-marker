# 立体书剪纸 MV


候选路线：有既有纸艺案例实践，仍不等于存在通用换歌产片引擎。本公开包尚未迁入这些历史作品。

1. 导演核表达、音乐/歌词录音与片段、时长、字幕选择、来源与可用资产。
2. 美术给纸页、书脊、角色/道具所属页、锚点与层序；背景、人物和投影共享变换。
3. 导演/动画把乐段变为任务→动作→对象反应→下一状态，抒情停留说明意图。
4. 先试折页/接触/遮挡风险段，核旧场退场、新场入场和阴影同步，不用镜头运动冒充主体行动。
5. 声音/后期按冻结 cue、源音轨和画面导出；保静音母版或带声候选的真实身份。
6. 验收分纸艺接触/层序、连续换场、行动可读性、技术、听看与用户采用。

五角色按 [paperbook-mv](../skills/paperbook-mv/SKILL.md)的 plan/art/motion/sound/review 模式取 PB/AN。文字可选；每首歌曲有自己的动作和时间结构。


执行时先恢复当前项目和有效基线；缺项只停相交步骤。各阶段交入目标、输入、写集与成本边界，交回具体产物、实际检查、未知和下一进入条件。
职责见 [agents](../agents/README.md)，技能由角色按当前阶段选择；必要返工直接回相交阶段，首次本地分享不另装循环或图执行器。
