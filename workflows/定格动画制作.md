# 定格动画


先选择程序纸艺逐格、实物拍摄或模型渲染，并核对应素材、设备/软件及能力。程序视频不冒称实物拍摄。

1. 导演确认目标、路线、规格、编码 fps 与姿态变化 Hz。
2. 美术锁角色、材质、机位、接触锚点和层序。
3. 导演/动画写分镜、源姿态、保持帧、接触与声 cue；分列正文时间和片头偏移。
4. 先做暴露最高接触/形变风险的短试镜；静态图不能证明动作。
5. 有效后扩全片，核固定纸纹/灯光、末姿态和实际尾帧；区分手作抖动与错误跳变。
6. 有适用且已采用系列片头时复用，是否组合及总时长单列。
7. 声音与后期核来源、混音、实际导出；验收核编码与声音及真实听看范围。
8. 用户反馈后局部返工，归档保可恢复的必要输入。

提高编码 fps 不等于增加独立姿态；设计尺寸、资产尺寸和编码分辨率分开记录。实物、黏土或三维工具能力不由程序纸艺案例证明。


执行时先恢复当前项目和有效基线；缺项只停相交步骤。各阶段交入目标、输入、写集与成本边界，交回具体产物、实际检查、未知和下一进入条件。
职责见 [agents](../agents/README.md)，技能由角色按当前阶段选择；必要返工直接回相交阶段，首次本地分享不另装循环或图执行器。

## 视频版本交付出口

本流程向用户交付已实际导出的视频版本（成片、初稿或试片）时，将本次文件/版本、实际内容与已知发表渠道交[声音与后期交付职责](../agents/声音与后期.md#video-delivery)，接回相邻Skill生成的完整交付信息，由宿主在最终回复实际展示。具体必交项由该职责消费的唯一原子定义，本页不复制正文。缺文件回原导出阶段，缺文案由原职责补齐；纯文档/归档结果、内部编码测试与未交付中间片不触发，不因此新做视频或自动发布。既有阶段、候选效力与采用条件保持。

<a id="video-public-entry"></a>
## 视频制作公共接入与返回

新建/修订本流程或实际进入、续作、视频/宣传交付时，将本候选版本/差异、目标阶段、基线、写集/位置、已有run和有效证据交[制作视频职责](../agents/制作视频.md#public-entry)，接其相邻公共Skill返回。入口不改变本流程方法状态或专用制作责任。

| 模式/落点 | 当前承担职责与实际消费 | 返回与缺项出口 |
|---|---|---|
| 流程候选接入 | 制作视频核逐项触发、阶段、职责与返回；文档维护核同候选覆盖后保存 | 接线覆盖与本轮媒体执行分列，缺接口回原作者，不以链接存在替代消费 |
| 当前制作/续作：路线、姿态/曝光编排及逐格制作 | 导演/动画按原题材Skill接已触发公共项；节奏判断/反馈进入animation-shot的AN13适配，声音取权威cue；文档维护接属性、位置和同run记录 | 返回需改/复用、真实时序/新增信息、验证与未知；缺项只停相交动作，保有效前缀 |
| 美术阶段：素材/舞台与接触锚点 | 美术保持本片采用身份；宣传或单独封面触发时取animation-shot静态封面适配 | 真实图像/来源/检查交回后期；无工具交可恢复输入，不假称出图 |
| 后期/交付：声音/编码与连续验收 | 声音与后期消费原视频交付出口；宣传封面结果取animation-finish封面适配，由制作视频核收后交宿主展示 | 缺视频回导出、缺封面只回相交图；非宣传不强制补图，补字段不重渲或发布 |

保存覆盖与实际结果沿本作已有计划/状态/事件/产出，格式见[公共覆盖空模板](../templates/project/public-defaults.md)。每项写原子ID/有效版本、触发、职责、阶段、证据/缺项和下一消费者；未触发注明条件/有据N/A，不能把空表当已消费。纯接线改动不生成媒体，专业工具能力与正常速度听看须以实际执行为准。
