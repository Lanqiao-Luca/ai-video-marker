# Blender分层角色动画制作

## 其他窗口从这里开始

本流程用于AI插画/既有分层美术驱动的Blender 2.5D有限动画：人物局部网格动作、独立附件、少量立体道具与运镜。完整三维人体、复杂转身/口型/流体未由本路线证明，收到这种观看承诺时先由导演核路线能力。

可直接交给另一个窗口：**“按《Blender分层角色动画制作》制作/接续【作品ID和题材】，目标【片长/画布/观看效果】，已有【图/音/工程及采用身份】，允许写集【路径】；先定位本run状态与首断点，按当前阶段返回输入缺项、执行位置和风险试段，再推进同版本交付。”** 已知信息沿用，不要求每次逐镜确认；只有影响当前执行的必要未知才返回。

入口链：本Workflow → 下表现有职责 → blender-layered-animation对应模式 → BL/既有AN原子 → 实际工具；返回沿原链。角色合同不表示平台安装或自动派生Agent。

## 公共准备与恢复

首次写媒体/源码/试片前，将目标/阶段、采用/候选、授权写集和环境交[制作视频](../agents/制作视频.md#public-entry)，取得相邻公共默认Skill同候选覆盖、触发项及专业责任；本流程不复制清单。文档与位置由[文档维护](../agents/文档维护.md)消费相邻animation-docs，返回process_root、必要delivery_root、外目录登记/恢复依赖和READY/具体缺项。把返回真实传给图像保存、Blender构建/渲染、声音/编码调用；原生图像缓存不能控制时据实记录并复制项目消费素材。

开始或接续沿本层执行文档保存计划、唯一状态、事件和产出，当前单元只读必要输入；存在有效run就续作，不重开并行总状态。位置变化先取更新绑定再写；收束核同版本交付、过程归属与恢复路径，域内保轻量记录和必要交付。纯文改不渲染，候选不自动替代采用版。

## 复用与已验证边界

新作按本作配置决定片长/画幅/动作fps，不能照抄某案坐标/骨骼数/采样率或绝对Home路径。实现边界由[动画职责](../agents/动画与合成.md#blender-layered-animation)经相邻Skill返回；缺工程时只能规划方法及恢复要求，不声称已有成果或重渲输入。工程包存在、CRC及静态路径核查不代异机恢复实跑。本流程active表示方法状态，本包没有附Blender构建/渲染器或工程，未按本路线制作公开代表段或全片。
