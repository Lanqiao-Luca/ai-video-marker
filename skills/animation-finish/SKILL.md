# 声画后期与验收

先区分请求，避免只核版本却重新渲染：

- 声音/色彩/编码：[AN05](../../standards/声音色彩与交付验收.md)。锁画面和音源身份，核 cue，复测最终编码。
- 版本/返工范围：[AN06](../../standards/版本资产与返工.md)，保留采用版、来源和无变化镜头。
- 作品验收：[AN07](../../standards/制作验证与阶段验收.md)及 [AN10](../../standards/动作因果与场内节奏.md)，技术、可读性、完整听看和用户采用分别记录。
- 同候选复核：[AN08](../../standards/审核交接与定向复核.md)；工具失败：[AN09](../../standards/渲染和工具异常恢复.md)。

[check_video.py](../../tools/check_video.py)可全解码和读规格；[contact_sheet.py](../../tools/contact_sheet.py)抽编码帧；[attach_audio.py](../../tools/attach_audio.py)为静音母版附加用户提供的音轨。命令和真实边界见 [工具说明](../../tools/README.md)。
音乐/录音/生成/合成来源分开，不能以母带数值代替最终音轨，也不能以自动检查代替听感。

按[AN05单源事件](../../standards/声音色彩与交付验收.md#event-source)让动画/声音/文字实际读取同一cue版本或同一值派生；记录唯一写者和失效区间，不能各处硬编码再声称共享。按[容器/码流色彩](../../standards/声音色彩与交付验收.md#container-bitstream-color)区分元数据与真实转换；技术、感知同步、正常速度听看和用户采用分别返回。

实际调用沿原角色交入的输入/过程/交付位置，参数改变先返回缺项或变更，不反向调度上层。长任务记录/预算读取范围沿[文档技能](../animation-docs/SKILL.md)交回原角色；不复制另一份总体进度。

只做场内动态验收时，接实际候选、动作链/阶段结果/接续、cue、正常速度可得范围与反馈，消费[AN10有限风险验收](../../standards/动作因果与场内节奏.md#连续风险段与验收)及AN07，返回实际观察、反证失败/修订点和未知。该分支不自动进入AN05制作、混音、编码或重渲；技术、场内表现与用户反馈/采用分别记，不能用技术PASS关闭动作不足的创作反馈。

<a id="video-delivery"></a>
## 视频交付与发布文案适配

接声音与后期角色交入的实际视频、内容、版本/候选身份与已知渠道，消费[AN11](../../standards/视频交付与发布文案.md)，返回同版本的文件位置、推荐标题、可直接使用的发布描述与具体缺项，供原角色/宿主在最终回复完整展示。核文件身份可复用同版本有效证据；只补文案不自动混音、重渲或发布。非视频结果与未交付内部编码不触发，本地路径不写进公开发布正文。

<a id="event-input"></a>
## 声事件输入适配

接原后期职责交入的实际音源、事件/偏移、唯一cue版本和变更范围，按AN05核权威来源与实际消费者读取证据，返回可复用引用/派生值、失效区间与未知。画面提速默认不改音乐速度，实际裁切/淡化独立记录；此接口复用现有后期方法，不引入新混音服务。

<a id="cover-delivery"></a>
## 宣传封面交付适配

接原后期职责的宣传目标、当前视频/源图/文案、位置和美术静态制作返回，消费[AN12](../../standards/视频宣传封面制作与交付.md)。先核触发/复用与制作输入，缺图交回原Workflow美术职责；已有图核同版本文件、实测规格、主文案、视觉检查与来源，返回完整交付或具体缺项，由制作视频职责核收、宿主展示。
此分支不混音、不重渲、不上传，图像制作和实际采用分别记录。仅方法接入不表示已生成宣传双图。
