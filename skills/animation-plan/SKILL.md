# 策划与分镜

接作品目标、当前阶段、已确认方向、输入与写集。只读取当前问题所需方法：

先使用 [素材准备与生成预算](../../standards/素材准备与生成预算.md)。无指定主题的首次创作默认复用仓库素材制作[海港机器人](../../examples/harbor/README.md)，不重渲首页展示片，不先要求素材三选一；执行入口与同seed试段规则沿AGENTS.md。明确复现展示时才用屋顶入口，明确新主题时不得退回固定默认片。用户开始自己的新作品时，再明确reuse/mixed/generate及具体来源。新素材可能需要更多时间、Token或服务调用，已有明确授权不重复问；缺少原件时不能暗中重造并冒称复用。素材路径/缺项与预算写进制作单。

- 范围/故事：[AN01](../../standards/制作单与故事拆解.md)。
- 角色与风格选择：[AN02](../../standards/角色与画面一致性.md)。
- 空间/镜头与动态分镜：[AN03](../../standards/镜头空间与动态分镜.md)。
- 行动节奏：[AN10](../../standards/动作因果与场内节奏.md)，返回场景任务→动作→对象反应/进展→下一状态；抒情停留说明目的。

填写 [项目模板](../../templates/project/README.md)。返回制作单、角色候选/采用、唯一空间和镜头时序、当前未知与下一进入条件。
动态分镜的平移缩放不冒称完整角色动画。缺素材或工具只停相交步骤；工具能力见 [工具入口](../../tools/README.md)。

新增制作前恢复[AN01观看用途与创意差异](../../standards/制作单与故事拆解.md#creative-difference)、[AN03目标画布](../../standards/镜头空间与动态分镜.md#target-canvas)与[AN10观看信息](../../standards/动作因果与场内节奏.md#viewing-information)：返回声音/文字类型、独特观看承诺、已知/新增信息及主要兑现停留。只换名或配色不能自证新故事，结尾已知信息不能误称反转。

实际调用沿原角色交入的输入/过程/交付位置，参数改变先返回缺项或变更，不反向调度上层。长任务记录/预算读取范围沿[文档技能](../animation-docs/SKILL.md)交回原角色；不复制另一份总体进度。

按[AN10动作推进合同](../../standards/动作因果与场内节奏.md#action-progression)接本段任务/体验、当前动作结果/停留、采用/反馈及真实cue，返回逐场可制作的动作链、阶段结果、接续、停顿用途与失败/未验；复用已有镜头字段，不另建时间线或CSV必填列。主体行动与舞蹈、动态文字、镜头探索等表达先辨适用，不强迫所有作品同一动作密度。

## 歌词／短句MV的转折创意适配

仅当《歌词／短句驱动程序动画MV》交入本片创意策划、换创意或“转折不足”反馈时使用。本路线明确复用[CRT-001–004](../../standards/像素节奏创意与连续性.md#crt-001-从物体自身结构产生唤醒机制)的结构触发、保留进展、状态跃迁和机制差异；这是本Skill的明确路线适配，不修改原像素原子的适用声明，也不将其VIS/CAM/QA条目扩到所有题材。按各CRT原有命中条件选用，普通叙事可采用选择、关系或用途的转折，不强制物体唤醒；转折不等同于结尾反转。

接原角色交入的文本/声音类型、观看承诺、既作机制、候选版本和用户真实反馈，调用CRT-001–004并沿[AN10](../../standards/动作因果与场内节奏.md#action-progression)组织动作与换场，返回到现有制作单/动作表字段：

- 先写终态或新功能及观众届时知道的新信息，再倒排可见前因、临界点与兑现时刻；效果应由前面的行动造成，不能用无因奇观或文案宣布完成。
- 逐场交回“触发→主动作→对象响应→保留结果→下一场接续”，标出每次新增的部件、关系、张力或功能；下一次触发应继承应保留的进展，不能反复归零。
- 比较既作与本片的环境和触发机制，说明哪些结构/关系决定了动作；只换名称、配色、载体或同一变形模板不能当成新机制。仅有物体互变但没有累积和可读兑现时，返回具体创意缺口。
- 将关键触发、累积到临界、跃迁和新功能兑现交给原动画/验收职责选连续风险片段；返回实际编码范围、可见接续、正常速度看听范围及失败点/UNKNOWN。动作与换场仍按AN10验收；技术解码或静帧通过不能关闭“转折不足”反馈。

失败时将缺因果、结果未保留、机制雷同或兑现不可读的具体段退回原cue与主动作阶段；只返工相交部分，保留有效输入和已有候选。未获使用者新反馈时保持未确认，不将作者判断或技术PASS升级为用户认可。本适配不安装技能、不触发其他题材、外审或发布。
