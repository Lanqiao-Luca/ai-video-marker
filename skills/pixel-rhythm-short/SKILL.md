**目的**：把事件、音乐与物体机制组织成可读的动作回报。

# 像素节奏短片

使用 [像素十二条方法](../../standards/像素节奏创意与连续性.md)及相交 AN；表单见 [12 份像素模板](../../templates/pixel/README.md)。各模式只读当前必要段：

| 模式 | 输入与产物 |
|---|---|
| music | 少量有依据的熟悉歌曲候选；核实际音源页、录音/原声版、片段起止与可用路径，固定后再定精确 cue |
| idea | 用户偏好→保留的机制与可替换载体；候选要有新环境和新触发，不能只换颜色 |
| mechanism | 已固定音乐/片段→物体结构、触发、逐步积累、临界状态和最终新功能 |
| layout | 唯一对象/地图、关系及相机→每镜任务、动作、对象反应、下一状态和 cue 可信度 |
| shot | 高风险连续段→实际编码与可读性范围；通过必要验证再扩全片 |
| check | 空间/身份、镜头连续、动作推进、技术及用户反馈分别给证据 |
| delivery | MP4、可用源码配置、音源来源/片段/cue、实际检查与待审项 |

默认优先熟悉的真实歌曲，具体平台由用户选择；老热门不冒称当前热榜。实际选歌时核来源，不凭记忆造链接。
没有可用音频时交静音母版及平台原声链接/时间范围；不绕保护、不以仿唱或其他录音偷换。原创配乐只在用户明确选择时制作。
源片段与视频时间保持同一口径；未精确听核的 cue 记待核。换录音或片段只使相交 cue、动作和证据失效。
像素原系列默认完整片不少于30秒、无文字、结尾有全局回应；这些是可按新作品明确需求调整的系列默认，不约束其他路线。

本包 [屋顶晒太阳示例](../../examples/pixel/README.md)直接抽取 PIXEL-010 的真实绘图实现，保留44秒角色、背景、动作和镜头；仓库包含新编程序合成配乐及生成源码，采用MIT许可；见 [配乐范围](../../examples/pixel/audio/NOTICE.md)。默认画面需通过 [逐帧来源回归](../../tools/check_pixel_baseline.py)，再核最终编码。新故事先在参考美术/动作基线下制作代表段，不得以新写的简化演示冒充能力抽取。原音乐同步、完整听审和用户采用分别保持真实状态。

首次创作且未指定题材时，按[海港机器人](../../examples/harbor/README.md)复用包内素材完成一支不同于首页展示的短片。三个现成场景、两套角色、可选配色与seed细节的边界见该入口；用户自己的明确主题优先，需实际适配故事与实现，不能只换名称、配色或默认重跑旧片。
