**目的**：说明各次公开框架升级同步了哪些本地能力及实际边界。

# 框架升级

## 0.3.0 · 2026-10-27

本次以已发布0.2.0为基线，仅同步下列增量。六层结构保持，8条内容流程（5正式方法、3候选）与2条辅助流程共用同一交付出口；正式方法状态与具体媒介执行分别记录。

| 变化 | 怎么使用 | 实际边界 |
|---|---|---|
| 新增参考音轨与AI漫画剪映路线 | 先核题材事实与画布，再冻结实际音轨、做代表图/样段、原生剪映编辑及交付 | 流程文档active；本包没有生图服务、剪映自动化或历史素材，未按新流程端到端实跑 |
| AN11统一视频交付 | 每次实际交付成片/试片/初稿时，给可见本地全路径、推荐标题、完整发布描述 | 非视频结果与未交付内部编码不触发，不重渲、不自动发布，本机路径不进公共文案 |
| 所有Workflow接同一出口 | Workflow→声音与后期角色→animation-finish→AN11，再沿原链返回宿主展示 | 不在每条流程复制规则；不改变候选或用户采用状态 |
| AN10逐场动作推进 | 前因/任务→施力或接触→响应→完成→接续，记阶段结果、cue与停顿用途 | 避免推拉/换场代替本片承诺的结果；舞蹈、动态文字、镜头探索与抒情保各自适用性 |
| 有限验收与真实反馈 | 先选定制作风险段，再正常速度核链条，保反证、未验和相交修订 | 技术PASS不关闭动作不足反馈，未知正常速度观感不写通过；仅待反馈不自动重渲 |
| 初始化新路线 | `--route reference-comic`带专题制作单；各新项目另有delivery.md空格式 | 只复制文字，不生成图片/音轨/影片、不启动剪映；原3个像素场景和默认海港不变 |

新路线可先输入：“按参考音轨与AI漫画流程，为《雨夜最后一班电车》给分镜、16:9画布与音轨/素材计划；先不造素材或下载音乐，列明真实能力与费用未知。”已有素材和需求直接沿用；实际需要新素材时才按既有策略补缺或生成。

```bash
python tools/init_project.py --route reference-comic --id night-tram --assets mixed --out outputs/night-tram
```

专题表单先记题材/参考证据、图像实际尺寸、音轨组成/片段/许可、工程/实际切点和检查范围。方形主体加柔化两侧只能叫背景填充版；需要真正宽幅细节则回美术补画/重绘，不能只改容器尺寸。

本次没有复制私人案例、音轨、图片、视频、工程、真实反馈或运行记录。验证与未验范围见[验证记录](VALIDATION.md)，逐文件源/目标身份见[来源清单](provenance.json)。

## 0.2.0 · 2026-10-26

本版对照维护者截至2026-10-26的本地现行方法，新增公开适配，不搬入私人执行记录。六层体系已有本地基础，公开版从四层补齐六层；绘画世界为新增候选路线。逐文件来源及目标SHA见[来源清单](provenance.json)。

| 变化 | 现在怎样使用 | 实际边界 |
|---|---|---|
| 四层补齐六层 | Graph按依赖，Loop按有限迭代，再交Workflow→Agent→Skill→Standards | 按需读取；无自动图执行器、后台调度或原生Agent安装 |
| 第7条路线：绘画世界穿行 | 先定结尾/母题，逆推空间路线，锁关键帧，试相邻两段与代表接缝 | candidate；方法/模板不等于图生视频服务或整片已制作 |
| PW01–05 | 参考证据、路线、生成交接、连续观看；选择画框退出时才取PW05 | 平面退出与完整三维穿行分别记录 |
| EX01/CX01 | 在同一项目记计划、唯一状态、事件、产出，只展开就绪单元 | 文件合同，由执行者维护；无自动持久化、锁、费用拦截或Token收益保证 |
| 策划/分镜 | 观看用途与画布、声音/文字类型、创意差异和独特观看承诺 | 换名/配色不自证新故事，静态取景不代全段安全 |
| 动作与试段 | 已知/新增信息、机制首次可见与兑现；风险覆盖到核心机制、变形中段/极值 | 无关难点通过不代卖点验证，拉远不自动等于反转 |
| 后期 | 单一event_id/版本/偏移由实际消费者读取；容器/码流色彩分层记录 | 不宣称已改造旧示例的事件/色彩实现；技术通过不代听看/采用 |
| MV流程泛化 | 按真实歌曲/短句及材质选通用Skill，纸艺才取PB分支 | 原paperbook ID兼容，仍candidate；没有通用换歌引擎 |
| 可复用画框函数 | RGB内外图+唯一凸四角+已缓动progress→RGB帧，可渐冻动态内图 | 可选NumPy/OpenCV，无文件读写、音轨、编码、服务调用或新素材 |

## 下载后怎么试

新人仍可直接运行默认海港机器人，原有3个可运行场景、12个文字案例和10组素材保持。新路线可先初始化文字工程：

```bash
python tools/init_project.py --route painting-world --id blue-studio --assets reuse --out outputs/blue-studio
```

对AI说：“从本作status.json开始，先确定结尾画面和逆推路线，再准备代表接缝输入包。只用当前适用素材，先核媒体能力和预算。”初始化器只复制表单与空记录，不制作图片/影片。

同一任务续作可说：“核计划与产物SHA、最近事件和未决动作结果，从第一个依赖就绪的单元继续，保留完成前缀。”实际需要重试才使用Loop，未给费用授权不因文档存在启动付费服务。

画框退出函数的可选安装和真实接口见[工具说明](../tools/README.md#painted-world)。可以只读方法，不安装其依赖；核心像素示例的依赖保持原样。
