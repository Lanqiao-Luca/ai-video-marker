## 0.5.0 · 2026-10-28

这次补齐本地已有但尚未公开的连续嵌套实现，同时同步新修订的像素动作速度默认；不是把所有能力都说成今天首次创建。来源按本轮读取冻结，未复制私人案例、时序预设、原文/运行记录、专用制作分支或新媒体。

| 变化 | 实际入口与行为 | 边界 |
|---|---|---|
| PW05连续嵌套 | 选择single_exit / continuous_nested_reveal / continuous_travel；嵌套保持完整前层复合世界，先试两次退出及接缝 | 绘画世界仍candidate，层数/时长/载体四角按本作，非全3D或图生视频 |
| 可选工具 | nested_world_reveal.py复用旧RGB/四角校验，矩阵累乘后每源单次采样，纯API及静音CLI；包导入与脚本模式均可用 | NumPy/OpenCV与CLI的FFmpeg另核；不造图、不resize、不生成音乐/字幕，不写剪映工程 |
| 相邻阶段与空模板 | 绘画世界Skill/Workflow的plan/art/motion/sound/review回本作，制作单加层链/显式适配/cue/两次试镜字段 | 空表不等于已执行，原状态与唯一run保持，无自动调度 |
| AN13更新 | 同类像素动作新制/返工相对原设计默认视觉r=2，音乐同录音1×，记录已执行倍率防续作叠乘；公共Skill消费当前版本 | 当前使用者参数和对白/阅读/抒情保护优先，不是所有题材2倍；旧3场景/18函数/1056帧不自动变速 |

可以对AI说：“按绘画世界候选流程准备一个连续两次退出的试镜，先给完整层链、统一画布/四角和cue，复用已有合规素材；不把单次缩回冒充多层体验。”工具命令与输入合同见[说明](../tools/多层嵌套揭示工具.md)。

106个已公开媒体原字节与素材中心路径全部保持。本次仅方法、空表、必要可选工具和测试；合成数组/临时小画布编码的实际检查见[验证](VALIDATION.md)，不代任何新题材全片、正常速度听看、用户采用或跨机成功。

## 下载后怎么试

新人仍可直接运行默认海港机器人，原有3个可运行场景、12个文字案例和10组素材保持。新路线可先初始化文字工程：

```bash
python tools/init_project.py --route painting-world --id blue-studio --assets reuse --out outputs/blue-studio
```

对AI说：“从本作status.json开始，先确定结尾画面和逆推路线，再准备代表接缝输入包。只用当前适用素材，先核媒体能力和预算。”初始化器只复制表单与空记录，不制作图片/影片。

同一任务续作可说：“核计划与产物SHA、最近事件和未决动作结果，从第一个依赖就绪的单元继续，保留完成前缀。”实际需要重试才使用Loop，未给费用授权不因文档存在启动付费服务。

画框退出函数的可选安装和真实接口见[工具说明](../tools/README.md#painted-world)。可以只读方法，不安装其依赖；核心像素示例的依赖保持原样。
